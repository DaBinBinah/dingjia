## 2. 今日技术攻关与决策复盘

### 2.1 微信推送通道技术选型与深度论证

| 方案 | 优缺点 / 限制 | 调研结论 | 最终决策 |
| :--- | :--- | :--- | :--- |
| **`Tencent/openclaw-weixin` (iLink Bot)** | ❌ 需常驻进程长轮询；`context_token` 仅几分钟有效且必须等用户先在微信发消息；无法随时异步主动推送 | 属于对话式 AI Agent 插件，不适合异步监控通知 | 明确不可行，避免引入脆弱中间件 |
| **微信公众平台测试号/服务号模板消息** | ✅ 微信官方原生接口；终身 100% 免费；无条数上限；直达微信服务通知；支持卡片一键直达 Web | 最优解，零成本，极度稳定 | ⭐ **主推第一通道（已上线）** |
| **Server酱 (Turbo / ³)** | 免费版 5 条/天，超出需付费 | 适合低频临时调试 | 保留兼容 |
| **PushPlus (推送加)** | 免费版 200 条/天（需个人 Token，非 SecretKey） | 适合备用 | 保留兼容 |
| **企业微信群机器人 Webhook** | 永久免费，无条数限制，需配置微信插件 | 适合办公场景 | 保持支持 |
