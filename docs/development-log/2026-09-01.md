## 7. 顾家家居基本面（PE/PB/ROE）排查与架构重构归档

### 7.1 问题现象
- 用户打开「顾家家居（603816）」详情页，基本面模块显示「PE(TTM) — 暂无估值数据」、「PB(MRQ) — 暂无市净率数据」、「ROE — 暂无报告期数据」，控制台报错「云函数 ths-get-fundamentals 调用失败」。

### 7.2 根因分析
1. **CloudBase 网关 Publishable Key 权限隔离**：
   - 前端匿名会话通过 Publishable Key 鉴权，云端网关对新增加的独立函数名 `ths-get-fundamentals` 未完全放行，导致客户端调用报错。
2. **前端 openDetail 重复并发调用导致数据踩踏覆盖**：
   - `openDetail` 内部先调用了 `renderDetail()` 发起请求 A，随后自身又发起请求 B，两次请求互相竞争，第二次未完成的请求将第一次成功渲染的结果覆盖为占位空值。
3. **同花顺 API 偶发限流（`request limit exceeded`）导致空数据被持久化为脏缓存**。

### 7.3 架构重构与修复方案
1. **合并服务路由（彻底解决网关权限）**：
   - 将基本面估值与盈利能力服务（PE/PB/ROE）深度集成进已授权的核心云函数 `ths-get-dividends` 中；
   - 详情页打开时，`mode=detail` 仅需 1 个请求即可同时带回分红日历与基本面数据，不仅彻底免去网关报错，还将详情页网络请求数量减少 50%。
2. **前端请求单例互斥锁（Inflight Lock）**：
   - 移除 `openDetail` 中的多余触发，并在 `loadDetailFundamentals` 中增加 `detailFundInflight` Promise 防抖锁，杜绝并发踩踏。
3. **缓存防空保护与 API 重试避让**：
   - 空数据绝对禁止写缓存，读缓存严格校验非空，遇限流自动延迟重试。
4. **全量发布**：
   - `ths-get-dividends` 云函数已部署上线，前端静态托管已发布至 `v20260901fund10`。

## 8. 近 52 周最高/最低价与今日市场四大指数功能开发归档

### 8.1 需求概述
1. **52 周最高/最低价**：以当前日期为基准向前滚动 52 周（364天），统计真实交易日极值，结合盘中实时行情，计算距最高/最低百分比，在详情页展示 Apple 风格极简分位指示条，并与「2026年至今」严格区分。
2. **今日市场四大指数**：展示沪指（上证指数 000001.SH）、深指（深证成指 399001.SZ）、创指（创业板指 399006.SZ）、科创50（000688.SH）的点位、涨跌点数、涨跌幅、更新时间；首页轻量卡片展示，详情页展示「我的标的 vs 大盘」相对强弱差值。

### 8.2 核心算法与数据源
- **52周时间范围**：`[nowMs - 52 * 7 * 86400 * 1000, nowMs]`，覆盖 240~245 个有效交易日。
- **历史数据不足**：若有效交易日小于 100 天，标记 `sufficient: false`，展示「数据不足（上市不满52周）」。
- **盘中数据合并**：在交易时间内将当日实时最高价 `dayHigh`、最低价 `dayLow` 与现价纳入极值比较，标记为含盘中数据。
- **四大指数数据源**：同花顺官方 API `/api/a-share/prices/snapshot` 批量单次请求。
- **缓存策略**：前端建立 30 秒全局单例缓存，首页与详情页共享大盘数据。

### 8.3 修改文件清单
1. `cloudfunctions/ths-get-history/index.js`：实现 52 周滚动极值与百分比计算。
2. `cloudfunctions/ths-get-market-overview/index.js`：定义四大指数与完整字段返回。
3. `cloudfunctions/ths-get-market-overview/lib/ths-api.js`：扩展字段提取。

## 10. 股票 / ETF 个人投资备注（投资笔记）功能开发归档

### 10.1 功能定位与核心原则
1. **纯用户个人长期投资笔记**：
   - 记录关注该标的的核心原因、设定买入/卖出价格的底层逻辑、行业与业绩关注点或投资思考心得。
2. **严格业务隔离**：
   - **与【投资日记】明确区分**：投资日记（`ths_notes`）按日流水记录，投资备注（`note`）为标的级长期稳定文本；
   - **与【投资计划】明确区分**：投资计划为结构化仓位与分批金额，投资备注为多行自由纯文本；
   - **绝不参与交易与计算**：备注文本绝不解析价格，绝不触发买卖预警，绝不影响资产、分红或估值指标；
   - **AI 安全隔离**：大模型绝不自动篡改用户备注内容。

### 10.2 数据库与模型设计
1. **集合与字段**：
   - 数据表：`ths_watchlist`（监控表）与 `ths_holdings`（持仓表）统一复用 `note` 字段；
   - 字段类型：`note`（`string`，支持多行，最大 1000 字符）、`noteUpdatedAt`（`Date`，最后修改时间）；
2. **监控与持仓联动**：
   - 既有监控又有持仓时，保存备注自动同步两处；
   - 删除监控不会误删持仓中的备注；删除持仓也不会误删监控中的备注。

### 10.3 界面与交互设计（Apple 风格）
1. **顶部轻量入口**：标的名称右侧带微型胶囊按钮（未备注显示灰度 `📝 备注`，已有备注显示高亮 `📝 已备注`），点击即可编辑；

   - 无备注时：展示轻量空状态并提供【＋ 添加备注】按钮；
3. **首页列表微型徽标**：已有备注标的在名称后呈现微型 `📝`，首页保持极简整洁；
4. **编辑弹窗（Modal / Bottom Sheet）**：

## 12. 中美双市场架构升级与美股行情全链路接入

### 12.1 业务背景与数据源技术决策
- **背景**：扩展“盯价”系统，使之不仅支持中国 A 股和中国 ETF，同时全面支持美股股票与美股 ETF 价格监控；
