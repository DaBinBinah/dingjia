## 二、数据库模型快照 (10 个集合)

1. `ths_watchlist`：监控标的与价格线、触达状态
2. `ths_price_touches`：目标价格精确秒级触达历史事件与快照
3. `ths_holdings`：持仓数量、成本价、计划投入
4. `ths_accounts`：现金账户与累计投入
5. `ths_plans`：投资逻辑、多档网格买卖点
6. `ths_notes`：投资复盘日记
7. `ths_user_settings`：交易佣金/印花税费率设置
8. `ths_dividends`：分红与收益分配日度缓存
9. `ths_alerts`：消息提醒流水
10. `ths_history_cache`：历史日 K 线缓存

## 四、安全与隔离规范

1. **环境隔离**：同环境根目录 `/` 为独立【亲子艺术】项目，本项目独占 `/ths/` 与 `ths_*` 集合/函数，绝对不交叉修改；
2. **凭据安全**：同花顺 API Key 与智谱大模型 API Key 均存放于云端环境变量，前端 SPA 无任何明文敏感配置；
3. **交易安全**：全系统定位于投资辅助仪表盘，严禁任何形式的自动委托或券商实盘交易接口。
